# Launch Strategy — Harf

> Mobile-First Arabic Learning Game for Indonesian Learners
>
> *Swipe. Battle. Streak. Rank.*

---

## 1. Launch Philosophy

Harf launches like a mobile game, not an education app. The difference is everything.

**Core tenets:**

- **Product-led growth.** The game itself is the best marketing. Every session generates a shareable moment. Every streak builds a story worth telling.
- **Community-first, not ad-first.** Zero ad spend at launch. All growth flows through TikTok, WhatsApp, Discord, and campus communities. Budget goes to creator incentives and referral rewards.
- **Viral by design, not by luck.** Sharing is baked into every core loop — rank promotion, streak milestone, battle victory, rare badge. Sharing is a reward, not an ask.
- **Retention before acquisition.** A user who invites 3 friends but churns on day 4 is a net negative. Streak mechanics, league relegation fear, and comeback rewards keep the core engaged. Acquisition only scales when D7 ≥ 60%.
- **Low-budget, high-leverage.** No billboards, no TV, no brand campaigns. TikTok organic, campus ambassadors, creator affiliate codes, WhatsApp chain sharing, and community events.

**Anti-patterns to avoid:**

- Launching with a press release and hoping for the best
- Spending budget on Facebook ads before retention is proven
- Using fake urgency ("Only 10 spots left!") — destroys trust, banned by app stores
- Spamming WhatsApp groups with unsolicited links
- Building features before validating demand

## 6. Viral Loop Design

Harf has five built-in viral loops. Each maps a core game action to a sharing trigger.

### Loop 1: Streak Flex (highest frequency)

**Trigger:** User hits a streak milestone (3, 7, 14, 30, 60, 100).
**Action:** App generates a shareable streak card with their avatar, streak count, and "I've learned Arabic for X days straight."
**Emotion:** Pride + mild superiority.
**Channel:** Instagram Story, WhatsApp Status, TikTok Story.
**Conversion:** Viewer taps link → App Store → signup → starts streak → wants to beat the original poster.

**Example card copy:**
> *"30 hari berturut-turut belajar Arab. No skip. No excuse."*
> *"Lo?"*
> *(Install button — "Challenge me")*

### Loop 2: League Promotion (highest status)

**Trigger:** User promotes to a new league (Perak → Emas → Sultan).
**Action:** Share card with league crest, user rank, and "I made it to Sultan League."
**Emotion:** Status display.
**Channel:** Instagram, WhatsApp, Discord.
**Conversion:** Friends want to join the same league → new users enter the competitive pipeline.

### Loop 3: Battle Victory (highest entertainment)

**Trigger:** User wins a battle (especially against higher-ranked opponent).
**Action:** Shareable GIF/video of the victory moment (enemy defeated animation + "I beat [username]").
**Emotion:** Trash talk (friendly).
**Channel:** TikTok, Instagram, Discord, WhatsApp.
**Conversion:** Loser wants rematch → installs app. Viewer thinks "I could beat them" → installs app.

### Loop 4: Rare Badge Unlock (highest prestige)

**Trigger:** User unlocks a rare achievement badge (<5% unlock rate).
**Action:** Share card with badge art and "Only 5% of players have this."
**Emotion:** Exclusivity.
**Channel:** Instagram, Discord.
**Conversion:** FOMO — others want the same badge.

### Loop 5: Combo Record (highest surprise)

**Trigger:** User hits a personal best combo (10+, 20+, 50+).
**Action:** Share card with combo count and "I answered 25 Arabic words in a row without a mistake."
**Emotion:** "Did that just happen?" surprise.
**Channel:** TikTok, Instagram.
**Conversion:** "That looks satisfying" → install.

**Viral loop efficiency targets:**
- Share conversion: 1 share per 5 sessions (target at launch)
- Install per share: 0.3-0.8 (target 0.5)
- Invited user D7 retention: ≥50%
- k-factor: ≥0.3 by month 3 (each user brings ≥0.3 new users)

## 15. Referral System Strategy

### Mechanics

**Direct referral:**
- Referrer gets 200 XP per friend who completes 3 sessions
- New user gets 100 XP bonus on signup (using referrer's code)
- Cap: 5,000 XP/month from referrals (prevents abuse)

**Streak referral bonus:**
- If referred friend maintains 7-day streak → referrer gets 500 XP bonus
- If referred friend reaches streak 30 → referrer gets 2,000 XP + exclusive "Mentor" badge

**Group referral:**
- Bring 5 friends (who complete 10 sessions) → "Squad Leader" badge
- Bring 10 friends → "Community Pillar" badge + avatar frame

### Referral Flow

1. User taps "Invite Friends" → generates unique link
2. Link opens share sheet with auto-copy
3. Shared via WhatsApp / Instagram / TikTok DM / Discord
4. Recipient taps → App Store → install → enters referral code at signup
5. Both receive XP notification within 24 hours

### Anti-Abuse

- Same device installs flagged and voided
- Requires 3 completed sessions for referral credit
- IP-based limits (max 5 referrals from same IP per day)
- Manual review for suspicious patterns

- Always warm, never guilt-tripping

## 18. Streak Reminder Psychology

Streak is Harf's most powerful retention lever. Its psychology must be designed with extreme care.

### The Streak Contract

When a user reaches Day 3, Harf surfaces a "Streak Contract" — an optional commitment:

> *"You're on Day 3. Want to make it official? I'll remind you every day. You just show up for 5 minutes. Deal?"*

This small psychological commitment increases streak stickiness by ~15-20%.

### Streak Visual Language

- **Active streak:** Green flame (🔥 with green glow)
- **Streak at risk:** Orange flame (pulsing animation)
- **Streak frozen:** Blue snowflake ❄️ (with freeze count remaining)
- **Streak broken:** Gray flame (somber animation, but encouraging message)
- **Streak milestone:** Gold flame with sparkle effect

### Streak Psychology Hacks

1. **Streak freeze tokens** — 1 every 7 days, max 2 stored. Reduces anxiety about missing a day.
2. **Grace period** — 3 hour buffer after midnight before streak breaks (accommodates night owls).
3. **"Recovery" mode** — If streak breaks, 3 days of comeback gameplay can restore it (once per 30 days).
4. **Streak preview** — Before breaking, show "You're about to lose X days" with the exact number.
5. **Streak celebration** — Every milestone gets a unique animation + sound (Day 7, 14, 30, 60, 100).

### Anti-Anxiety Design

- Streak freeze is clearly explained upfront (not hidden)
- "Night Owl" mode lets users set their own streak reset time (e.g., 3 AM)
- Streak is a reward, not a punishment — loss recovery is easy, not punishing
- "Rest day" option: 1 rest day per week where streak freezes automatically

## 19. FOMO-Based Retention

FOMO is used sparingly and ethically. The goal is healthy urgency, not anxiety.

### Ethical FOMO Mechanisms

1. **League relegation** — "Only 3 safe spots left in Emas League. 2 days remaining."
   - Ethical because: It's real. The league has limited safe spots.
   - Unethical version: Fake "5 spots left!" countdown that resets.

2. **Limited-time badges** — "Ramadan 1446 badge — available until Eid. 12 days left."
   - Ethical because: It's a real time-limited event.
   - Unethical version: "Only 10 left!" for a digital badge with no scarcity.

3. **Friend passed you** — "Rizky just passed you in the league rankings. 👀"
   - Ethical because: It's factually true. Social comparison is natural.
   - Unethical version: "5 friends passed you today" when only 1 passed.

4. **Streak at risk** — "Day streak: 23. Cutoff: 2 hours."
   - Ethical because: The user chose to start the streak. Honest countdown.
   - Unethical version: Hidden streak freeze, confusing streak rules.

5. **Unclaimed rewards** — "Daily reward unclaimed. Resets in 1 hour."
   - Ethical because: The reward is real and time-bound by daily reset.

## 46. Retention Analytics

### Retention Waterfall

Track and optimize every step:

```
Install → Signup → Session 1 → Session 3 → D7 → D14 → D21 → D30 → D60 → D90
```

**Diagnostic questions at each drop-off:**

| Drop-off | Diagnosis |
|---|---|
| Install → Signup | Friction in signup flow (too many steps, errors) |
| Signup → Session 1 | First session not engaging enough, onboarding unclear |
| Session 1 → Session 3 | Day 2-3 notification not compelling, no streak started |
| Session 3 → D7 | Battle not unlocked or not engaging, no league placement |
| D7 → D14 | No friend connection, no social retention hook |
| D14 → D30 | Content fatigue, league stagnation, no new features |

### Churn Prediction Model

**High churn risk signals:**
- Session length <2 minutes for 3 consecutive sessions
- Session gap >48 hours (after streak established)
- Negative sentiment on post-session emoji slider
- No friend connections after 7 days
- No battle participation after 7 days
- Declining accuracy rate (swipe learning)

**Churn prevention interventions:**
- High risk: "Comeback bonus" notification + 200 XP offer
- Medium risk: Notification with new content (word pack, battle enemy)
- Low risk: "Your friend [name] passed you in the league" notification

### Retention by Segment

| Segment | Expected D7 | Expected D30 | Strategy |
|---|---|---|---|
| Referral signups | 30% | 15% | Social connection leverage |
| Creator-driven signups | 25% | 12% | Content alignment |
| Organic/ASO signups | 15% | 8% | Onboarding optimization |
| Campus signups | 35% | 20% | Peer competition, exam motivation |
| School pilot signups | 40% | 25% | Required usage, teacher pressure |
