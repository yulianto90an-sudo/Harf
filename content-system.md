# Content System — Harf

> Content is the product. Every word, every lesson, every battle question is a deliberate component in a progression system designed for retention, mastery, and genuine Arabic communication ability.

---

## 1. Content System Philosophy

Harf's educational content rests on four pillars:

**1. Learning is the reward.**  
The content is designed so that understanding a new word or phrase *feels* like the reward — not just the XP that follows. Comprehension is its own dopamine hit.

**2. Arabic-first, but Indonesian-native.**  
All content is authored in Arabic first (script, pronunciation, meaning), then translated to Indonesian. The learner's native language is a bridge, not a crutch. Transliteration exists to be outgrown.

**3. Retention over coverage.**  
It is better to know 100 words permanently than 1000 words fleetingly. Every content decision optimizes for long-term retention: spaced repetition, deliberate overlearning, contextual reinforcement.

**4. Conversation readiness.**  
Every piece of vocabulary is selected for its utility in real conversation. No archaic words. No irrelevant categories. Every word should be usable in a sentence the learner might actually say.

---

## 2. Educational Design Principles

| # | Principle | Definition | Application |
|---|-----------|------------|-------------|
| 1 | **Gradual Complexity** | Content complexity increases in lockstep with learner ability | Lessons unlock only when prerequisite mastery is demonstrated |
| 2 | **Contextual Meaning** | Words are learned in phrases, not isolation | Every word appears in at least one example sentence |
| 3 | **Active Recall** | Retrieval strengthens memory | Swipe mode tests recall, not recognition |
| 4 | **Interleaving** | Mix categories within sessions | Each swipe session pulls from 2-3 categories |
| 5 | **Overlearning** | Correct beyond 80% is mastery | Words aren't "learned" until 5 consecutive correct |
| 6 | **Error-Driven Learning** | Mistakes strengthen memory | Wrong answers trigger immediate correction + re-exposure |
| 7 | **Desirable Difficulty** | Hard enough to grow, easy enough to continue | 80-90% target accuracy per session |
| 8 | **Serial Positioning** | Primacy & recency effects | New words appear in middle of session (optimal encoding) |
| 9 | **Multimodal Input** | See, hear, speak, write | Each word is read, heard, spoken (future), and swiped |
| 10 | **Emotional Anchoring** | Emotion strengthens memory | Reward sounds, mascot reactions, and combo streaks anchor vocabulary |

## 3. Learning Progression Architecture

### 3.1 Journey Stages

```
Stage 1: Absolute Beginner (Levels 1-5, ~45 min playtime)
  Goal: Recognize Arabic script, read basic words, pronounce simple greetings
  Vocabulary: 30 words (greetings, introductions, basic courtesies)
  Grammar: None — pure vocabulary acquisition
  Unlocks: Battle mode at Level 5

Stage 2: Basic Survival (Levels 6-12, ~4 hours)
  Goal: Understand common daily phrases, introduce self, ask simple questions
  Vocabulary: 100 words (family, food, numbers, colors, places)
  Grammar: Gender, basic verb conjugation (present tense)
  Unlocks: Daily missions, streak system

Stage 3: Daily Conversation (Levels 13-25, ~20 hours)
  Goal: Hold simple conversations about familiar topics
  Vocabulary: 300 words (emotions, time, weather, shopping, directions)
  Grammar: Past tense, possessive, prepositions, questions
  Unlocks: Profile customization, social features

Stage 4: Quranic Familiarity (Levels 26-40, ~50 hours)
  Goal: Recognize common Quranic vocabulary, understand prayer phrases
  Vocabulary: 200 additional words (worship, ethics, stories)
  Grammar: Quranic grammar patterns, dual/plural forms
  Unlocks: Quranic vocabulary track

Stage 5: Intermediate Communication (Levels 41-65, ~120 hours)
  Goal: Express opinions, describe experiences, discuss abstract topics
  Vocabulary: 500 additional words (business, news, culture, technology)
  Grammar: Subjunctive, conditional, passive voice
  Unlocks: Advanced battle league

Stage 6: Advanced Mastery (Levels 66-100, ~500+ hours)
  Goal: Near-fluent conversation, media comprehension, written expression
  Vocabulary: 1000+ additional words (idioms, literature, specialized)
  Grammar: All major patterns, complex sentence structures
  Unlocks: AI conversation partner, writing exercises
```

### 3.2 Lesson Unlock Logic

```
Lesson n+1 is unlocked when:
  - All lessons in previous tier are at ≥80% mastery
  - OR cumulative XP threshold is met (casual path)

Casual path thresholds:
  Stage 1→2:    1,000 XP (allows skipping lessons if user is ahead)
  Stage 2→3:    5,000 XP
  Stage 3→4:   15,000 XP
  Stage 4→5:   50,000 XP
  Stage 5→6:  200,000 XP

The casual path exists so advanced learners can move faster.
The mastery path exists so beginners build solid foundations.
Both paths converge at stage boundaries.
```

### 3.3 Mastery Thresholds

| Level | Label | Criteria |
|-------|-------|----------|
| 0 | Unseen | Word has not been introduced |
| 1 | Introduced | Word appeared in lesson once |
| 2 | Practiced | Word has been swiped 1-3 times |
| 3 | Familiar | Word answered correctly 2-3 consecutive times |
| 4 | Learned | Word answered correctly 5+ consecutive times |
| 5 | Mastered | Word maintained ≥80% accuracy over 30+ day review interval |

### 5.2 Word Selection Criteria

Each word must pass all of these gates before being added to the curriculum:

1. **Frequency:** Is this word used in everyday Arabic conversation? (top 5,000 words target)
2. **Utility:** Can the learner use this word in a sentence within 2 lessons of learning it?
3. **Learnability:** Is the concept translatable to Indonesian without cultural loss?
4. **Composability:** Does this word combine with previously learned words?
5. **Necessity:** Would the learner be unable to express something important without this word?

### 5.3 Word Difficulty Classification

```
Easy (40% of vocabulary):
  - Cognates or familiar concepts (madrasah = sekolah, kitāb = buku)
  - Short words (1-3 letters in root)
  - High-frequency, high-utility
  - Introduced in Stages 1-2

Medium (35% of vocabulary):
  - Requires understanding of grammatical gender
  - Slightly longer words (3-5 letters in root)
  - Moderate frequency
  - Introduced in Stages 2-4

Hard (25% of vocabulary):
  - Complex root patterns
  - Abstract concepts
  - Lower frequency, specialized
  - Introduced in Stages 4-6
  - May have irregular plural forms
```

## 6. Lesson Structure System

### 6.1 Lesson Anatomy

Each lesson follows a consistent 6-phase structure optimized for mobile microlearning:

```
Phase 1 — Introduction (30 seconds)
  Screen:    Lesson title + mascot contextual message
  Content:   "Hari ini kita belajar 8 kata tentang keluarga!"
  Emotion:   Curiosity, anticipation
  Audio:     Mascot chirp (happy)
  Skip:      User can tap to skip to Phase 2

Phase 2 — Vocabulary Exposure (60 seconds)
  Screen:    Flashcards with Arabic, Latin, Indonesian, audio
  Content:   8 new words, each shown for 5 seconds
  Interaction: User taps audio button on each card
  Emotion:   New information intake, low cognitive load
  Note:      No testing yet — pure exposure

Phase 3 — Swipe Reinforcement (3-4 minutes)
  Screen:    VocabCard stack with swipe mechanics
  Content:   8 new words + 4 review words from 3+ sessions ago
  Interaction: Swipe right (known) or left (unknown)
  Emotion:   Active recall, satisfaction from correct answers
  Combo:     Streak tracking begins

Phase 4 — Listening Practice (60 seconds)
  Screen:    Audio plays Arabic word, user selects meaning
  Content:   5 questions from Phase 3 words
  Interaction: Tap correct Indonesian translation
  Emotion:   Challenge mode — ear training
  Difficulty: Audio speed: normal (slow option available)

Phase 5 — Mini Battle (2 minutes)
  Screen:    Simplified battle interface
  Enemy:     Easy enemy (HP: 40, no timer pressure)
  Content:   3 questions from today's vocabulary
  Interaction: Tap correct answer
  Emotion:   Excitement, application of knowledge
  Reward:    Bonus XP for perfect round

Phase 6 — Recap + Rewards (30 seconds)
  Screen:    Session summary with stats
  Content:   XP earned, combo, accuracy, new words
  Emotion:   Accomplishment, pride
  Bonus:     Streak progress shown
  Duration:  5 minutes total per lesson (ideal mobile session)
```

### 6.2 Lesson Length Rules

| Factor | Value | Rationale |
|--------|-------|-----------|
| New words per lesson | 8 | Cognitive load limit for mobile microlearning |
| Review words per lesson | 4 | Minimum for effective spaced repetition |
| Total cards per session | 12 | Optimal for 3-4 minute swipe session |
| Lesson duration | 4-6 minutes | Mobile attention span sweet spot |
| Maximum consecutive lessons | 3 | Beyond 3, retention drops significantly |

### 6.3 Lesson Types

| Type | Focus | Phases | Duration |
|------|-------|--------|----------|
| Standard | New vocabulary | Intro → Exposure → Swipe → Recap | 5 min |
| Listening | Ear training | Mini battle (audio only) → Recap | 3 min |
| Review | Spaced repetition | Swipe (review only) → Recap | 4 min |
| Battle Challenge | Speed + recall | Battle mode only | 3 min |
| Conversation | Phrase building | Sentence construction → Swipe | 6 min |
| Grammar | Rule learning | Explanation → Examples → Swipe | 5 min |

## 7. Difficulty Scaling System

### 7.1 Vocabulary Complexity

Difficulty scales across five dimensions:

```
1. Word Length (Arabic script)
   Easy:   1-3 characters (مَاء, بَيْت, قَلَم)
   Medium: 4-5 characters (مَدْرَسَة, صَدِيق)
   Hard:   6+ characters (السَّلَامُ عَلَيْكُمْ)

2. Root Pattern Regularity
   Easy:   Regular triliteral roots (كَتَبَ → كِتَاب)
   Medium: Hamzated or weak roots
   Hard:   Quadriliteral or rare patterns

3. Abstractness
   Easy:   Concrete objects (book, house, water)
   Medium: Actions (to eat, to go, to write)
   Hard:   Abstract concepts (freedom, patience, justice)

4. Similarity to Indonesian
   Easy:   Cognates (madrasah, kitāb, qalam)
   Medium: Non-cognates but simple concepts
   Hard:   No Indonesian equivalent

5. Grammatical Complexity
   Easy:   Masculine singular, no case endings
   Medium: Feminine, plural, construct state
   Hard:   Dual, irregular plural, case endings in context
```

### 7.2 Session Difficulty Curve

Within each session, difficulty follows a controlled arc:

```
  Easy (cards 1-2):    Warm-up — words user has seen before
  Medium (cards 3-7):  New vocabulary — core learning zone
  Hard (card 8):       Challenge word — slightly above current level
  Review (cards 9-12): Mixed difficulty — spaced repetition

Accuracy target:
  Card 1-2:   90-100% (confidence building)
  Card 3-7:   70-85%  (learning zone — desirable difficulty)
  Card 8:     40-60%  (stretch — expected to be challenging)
  Card 9-12:  80-95%  (review — strengthening memory)
```

### 7.3 Battle Difficulty Scaling

```
Enemy difficulty determines:
  - Vocabulary tier (which words are available)
  - Answer time pressure (timer duration)
  - Question complexity (direct vs contextual translation)

Easy enemy (HP: 60):
  Words from: Current lesson only
  Timer:      15 seconds per question
  Question:   "What does X mean?" (direct translation)
  Options:    4 simple distractors

Medium enemy (HP: 100):
  Words from: Current lesson + 2 previous lessons
  Timer:      10 seconds per question
  Question:   "Which word means X?" (reverse translation)
  Options:    4 distractors from same category

Hard enemy (HP: 140):
  Words from: Current lesson + 5 previous lessons
  Timer:      7 seconds per question
  Question:   "Complete the sentence: _____" (contextual)
  Options:    4 distractors with similar meanings
```

## 9. Grammar Progression

### 9.1 Grammar Introduction Timing

Grammar is never taught explicitly in isolation. It emerges through vocabulary usage patterns, with contextual hints.

```
Stage 1 (Levels 1-5): No grammar
  Focus: Vocabulary only
  All nouns presented in masculine singular form
  No verb conjugation, no case endings

Stage 2 (Levels 6-12): Gender + Basic Verbs
  Pattern exposure: Noun gender (kitāb vs madrasah)
  Verb introduction: Present tense, 3rd person masculine singular
  Question words: mā, man, kayfa, ayna
  Prepositions: fī, 'alā, ilā, min

Stage 3 (Levels 13-25): Past Tense + Possessive
  Past tense conjugation (3rd person patterns)
  Possessive suffixes (-ī, -ka, -kī, -hu, -hā)
  Plural patterns (sound masculine, sound feminine)
  Comparative/superlative (af'alu pattern)

Stage 4 (Levels 26-40): Quranic Patterns + Dual
  Dual forms (noun, verb, adjective)
  Broken plural patterns
  Quranic grammar: nominal sentences, emphasis
  Case endings (marfū', mansūb, majrūr) — recognition only

Stage 5 (Levels 41-65): Complex Structures
  Subjunctive mood
  Conditional sentences (in, law, idhā)
  Passive voice (form I-VIII)
  Relative clauses

Stage 6 (Levels 66-100): Mastery
  All verb forms (I-X)
  Complex sentence embedding
  Stylistic variations
  Poetry meter basics (for literature track)
```

### 9.2 Grammar Presentation Pattern

```
Every grammar concept follows this 4-step pattern across consecutive sessions:

Session 1: Implicit exposure — word appears in context with the pattern
Session 2: Pattern notice — "Did you notice how X changes to Y?"
Session 3: Active use — user must produce/swipe the correct form
Session 4: Reinforcement — word appears in mixed review with the pattern highlighted
```

## 11. Pronunciation System

### 11.1 Letter Progression

Arabic letters are introduced gradually, not all at once. The order prioritizes:

1. Letters that exist in Indonesian (b, t, d, f, k, l, m, n, r, s, w, y) — 12 letters
2. Letters with close Indonesian approximations (dh, zh, sh, gh, kh) — 5 letters
3. Emphatic letters (ṣ, ḍ, ṭ, ẓ) — 4 letters
4. Unique Arabic letters (ʿayn, ḥā', hamza, qāf) — 4 letters
5. Rare letters (th, dh in specific contexts) — 2 letters

### 11.2 Pronunciation Exercises (Future)

```
Phase 1 (Stage 1): Passive recognition
  User hears letter → sees letter → taps to confirm
  
Phase 2 (Stage 3): Active production
  User hears word → records pronunciation → AI scores accuracy
  
Phase 3 (Stage 5): Fluency
  User reads sentence aloud → AI evaluates fluency
```

## 12. Conversation Training System

### 12.1 Phrase Building

Words are combined into phrases starting from Stage 3:

```
Example progression for "makan" (to eat):

Lesson 8:  أَكَلَ  (he ate) — vocabulary
Lesson 10: أَكَلَ خُبْزًا (he ate bread) — verb + object
Lesson 12: هُوَ أَكَلَ خُبْزًا (he ate bread) — pronoun + verb + object
Lesson 15: هَلْ أَكَلْتَ خُبْزًا؟ (did you eat bread?) — question form
Lesson 18: أَنَا لَمْ آكُلْ خُبْزًا (I didn't eat bread) — negation
```

### 12.2 Conversation Scripts

Starting from Stage 3, lessons include 2-line dialogs:

```
Stage 3 example:
  A: السَّلَامُ عَلَيْكُمْ
  B: وَعَلَيْكُمُ السَّلَام
  A: كَيْفَ حَالُكَ؟
  B: أَنَا بِخَيْرٍ، شُكْرًا

Stage 5 example (longer, more natural):
  A: هَلْ ذَهَبْتَ إِلَى السُّوقِ الْيَوْمَ؟
  B: نَعَمْ، ذَهَبْتُ وَاشْتَرَيْتُ فَاكِهَةً
  A: مَاذَا اشْتَرَيْتَ؟
  B: اشْتَرَيْتُ تُفَّاحًا وَمَوْزًا
```

## 13. Swipe Learning Content Rules

### 13.1 Card Content Structure

```
Each VocabCard in swipe mode displays:

Front of card (always visible):
  [Category tag]                    — e.g., "Salam"
  [Arabic word in large script]     — e.g., السَّلَامُ
  [Latin transliteration]           — e.g., As-Salām
  [Swipe hint]                      — "Geser ke kanan jika benar"
  [Audio button]                    — tap to hear pronunciation

On correct swipe (right):
  Green glow overlay
  "BENAR!" label
  XP burst animation
  Card exits right

On incorrect swipe (left):
  Red glow overlay
  "SALAH" label
  Card shows correct Indonesian meaning
  Card exits left
  Word scheduled for re-exposure

Review card (word seen before):
  Same layout but no swipe hint (user knows the mechanic)
  Slightly smaller Arabic text (signals "this is review")
  "(Review)" tag on category label
```

### 13.2 Swipe Distractor Generation

```
Incorrect options are generated from the SAME category, not random words:

Correct:  شُكْرًا → "Terima kasih"
Options:  "Terima kasih" ✓, "Selamat pagi" ✗, "Maaf" ✗, "Silakan" ✗
All options are from Salam/Sopan Santun category
This forces the learner to distinguish between similar domains

Exception: Review sessions use cross-category options (harder)
```

### 13.3 Word Recurrence Rules

```
Correct answer:
  Next appearance: +3 cards later (immediate review)
  Then: end of session (serial position effect)
  Then: next session (spaced repetition)

Wrong answer:
  Next appearance: +2 cards later (faster review)
  Then: +3 cards after that (additional reinforcement)
  Then: start of next session
  Then: scheduled for intensive review (see Section 16)
```

## 14. Battle Mode Content Rules

### 14.1 Question Generation Algorithm

```
BATTLE_QUESTIONS_PER_ROUND = 5

Each battle question picks from the correct word pool:

Pool selection:
  60% chance: Words from current lesson
  30% chance: Words from last 3 lessons
  10% chance: Words from "weak" list (lowest mastery)

Wrong answer generation:
  Same category (60%) — forces precise meaning recognition
  Adjacent category (30%) — encourages cross-domain knowledge
  Random (10%) — mild distractor variety

Difficulty adjustment:
  If previous answer was wrong: simplify next question
    (same word, clearer distractor difference)
  If previous 3 answers correct: increase next question difficulty
    (tighter distractor similarity, reverse translation)
```

### 14.2 Enemy Vocabulary Mapping

```
Easy enemies (👻 Hantu Kosakata, HP: 60):
  Word pool: Current lesson only
  Question type: "What does X mean?" (forward translation)
  Distractors: Different categories (easy to distinguish)
  Timer: 15 seconds

Medium enemies (🗿 Golem Tata Bahasa, HP: 100):
  Word pool: Current + 2 previous lessons
  Question type: "Which word means X?" (reverse translation)
  Distractors: Same category (harder to distinguish)
  Timer: 10 seconds

Hard enemies (🐉 Naga Arab, HP: 140):
  Word pool: Current + 5 previous lessons
  Question type: Mix of forward, reverse, and fill-in-blank
  Distractors: Similar meaning words
  Timer: 7 seconds

Boss (👑 Raja Iblis, HP: 180):
  Word pool: All learned vocabulary (minimum 50 words)
  Question type: Random across all types
  Distractors: Highest difficulty
  Timer: 5 seconds
  Reward: 2x XP, exclusive badge
```

### 14.3 Combo Pressure Balance

```
Combo system applies pressure but never punishes learning:

  Combo 2-4: Enemy takes normal damage
    → Encourages accuracy without pressure

  Combo 5-7: Enemy takes 1.5x damage
    → "You're doing great!" boost

  Combo 8+: Special attack unlocked
    → 2x damage + visual spectacle
    → "This is the peak" feeling

  Wrong answer: Combo resets, no additional penalty
    → No damage multiplier for enemy
    → No special punishment
    → Word goes to "weak" list for review

Balance: A player at 80% accuracy should win most battles.
A player at 60% accuracy should lose occasionally but not be locked out.
```

| Conversation complete | 25 | — | Longer engagement reward |
| Daily mission | 25-100 | — | Variable by mission type |

### 15.2 XP Decay for Repeated Words

```
Each time a word is answered correctly in the SAME session:
  1st correct: Full XP
  2nd correct: 80% XP
  3rd correct: 60% XP
  4th+: 40% XP

This prevents grinding the same easy words for XP
and encourages learning NEW vocabulary.

Resets every session (new lesson = fresh word XP).
```

## 16. Spaced Repetition Strategy

### 16.1 Review Intervals

Harf uses a modified SM-2 algorithm optimized for mobile microlearning:

```
After correct answer:
  1st review:   4 hours   (same day)
  2nd review:   24 hours  (next day)
  3rd review:   3 days
  4th review:   7 days
  5th review:   14 days
  6th review:   1 month
  7th+ review:  2 months (maximum interval)

After wrong answer:
  Return to 4-hour interval
  Word enters "intensive review" pool
  Appears in every session until 3 consecutive correct
  Maximum 2 intensive words per session (prevents overload)
```

### 16.2 Memory Decay Logic

```
Ease factor (EF) per word, initialized at 2.5:

On correct:
  EF' = EF + (0.1 - (5 - q) × (0.08 + (5 - q) × 0.02))
  Where q = quality of recall (1-5):
    5 (immediate):   EF += 0.1
    4 (hesitant):    EF unchanged
    3 (difficult):   EF -= 0.14
    2 (wrong but close): EF -= 0.3
    1 (complete forget): EF -= 0.4

  Minimum EF: 1.3 (prevents infinite intervals)
  
  Next interval = current interval × EF

On wrong:
  Interval resets to 4 hours
  EF decreases (see above)
  Word requires 3 consecutive correct to exit intensive review
```

### 16.3 Weak Word Resurfacing

```
The "weak word pool" contains all words with EF < 2.0:

Session composition when weak pool > 10 words:
  40% new words
  30% scheduled review words
  30% weak pool words

Session composition when weak pool > 30 words:
  20% new words
  30% scheduled review words
  50% weak pool words
  (New word introduction slows down when backlog exists)

This prevents the "leaky bucket" problem
where new words push out old, unmastered words.
```

### 16.4 Adaptive Reinforcement

```
Each session adjusts its content based on the user's history:

If user struggles with a specific category (accuracy < 60%):
  → More review words from that category
  → Fewer new words from that category
  → Simpler distractors in battle

If user excels at a specific category (accuracy > 95%):
  → Fewer review words (free up slots)
  → More new words from related categories
  → Harder distractors in battle
  → Word is moved to "mastered" faster

If user is on a streak (5+ days):
  → Slight increase in new words per session (bonus confidence)
  
If user is returning from absence (3+ days no activity):
  → 80% review, 20% new (rebuild foundation)
  → Easy enemies in battle (rebuild confidence)
```

### 21.2 Retention Design Decisions

```

   → Short sessions increase return frequency

   → 8 hits the sweet spot for mobile microlearning

3. Review ratio increases with stage
   → Beginners need more exposure per word
   → Advanced learners need maintenance, not introduction

4. Weak word pool limits new word introduction
   → Prevents accumulation of unmastered vocabulary
   → Keeps quality bar high

5. Streak freeze and comeback bonuses
   → 1 missed day = no penalty
   → 3+ missed days = enhanced review (not punishment)
```

### 23.2 Arabic Text Sizing

```
Context | Tailwind Class | Size | Line Height
---------|---------------|------|-------------
Word display (main card) | text-arabic-xl | 2.5rem | 1.1
Word display (battle) | text-arabic-l | 2rem | 1.2

Example sentence | text-body | 1rem | 1.5

### 23.3 Readability Rules

```
1. Minimum Arabic font size: 1.25rem (20px) on mobile
   Below this, diacritics become unreadable

2. Line-height for Arabic: minimum 1.4x
   Arabic script needs more vertical space than Latin
   Descenders and diacritics overlap at tight line-height

3. Letter-spacing: 0 (never add tracking to Arabic)
   Arabic is cursive — letter-spacing breaks connections

4. Word-spacing: normal
   Arabic words are separated by a space, not by letter gaps

5. Direction: always dir="rtl" on Arabic text elements
   lang="ar" attribute required for screen reader support

6. Diacritics (tashkīl): always present in learning content
   Essential for pronunciation clarity
   Gradually fade in advanced content (real-world texts don't have them)

7. Contextual forms: rendered correctly by the font
   Noto Naskh Arabic handles initial/medial/final/isolated forms
   No manual form selection needed
```

## 24. Transliteration Rules

### 24.1 Transliteration Standard

Harf uses a simplified, beginner-friendly transliteration system — NOT academic IJMES or Library of Congress standards.

```
Consonants:
  ا  →  ā       (long vowel)
  ب  →  b
  ت  →  t
  ث  →  th      (as in "think")
  ج  →  j
  ح  →  ḥ       (emphatic h, like breathing on glass)
  خ  →  kh      (as in "Bach")
  د  →  d
  ذ  →  dh      (as in "this")
  ر  →  r
  ز  →  z
  س  →  s
  ش  →  sy      (as in "shy")
  ص  →  ṣ       (emphatic s)
  ض  →  ḍ       (emphatic d)
  ط  →  ṭ       (emphatic t)
  ظ  →  ẓ       (emphatic dh)
  ع  →  '       (ayn — apostrophe)
  غ  →  gh      (as in French "r")
  ف  →  f
  ق  →  q       (deep k from throat)
  ك  →  k
  ل  →  l
  م  →  m
  ن  →  n
  ه  →  h
  و  →  w / ū   (consonant / long vowel)
  ي  →  y / ī   (consonant / long vowel)
  ء  →  '       (hamza — apostrophe)

Vowels:
  ـَ  →  a       (fatḥa)
  ـُ  →  u       (ḍamma)
  ـِ  →  i       (kasra)
  ـًا  →  an     (tanwīn fatḥ)
  ـٌ  →  un     (tanwīn ḍamm)
  ـٍ  →  in     (tanwīn kasr)

Special:
  ة  →  h / t   (tā' marbūṭa: h in isolation, t in construct)
  ال  →  al-     (definite article, hyphenated)
  ّ  →  double letter (shadda)
  ـْ  →  omitted (sukūn — no vowel)
```

### 24.2 Readability Rules for Transliteration

```
1. Use ASCII-friendly symbols only
   → ḥ, ṣ, ḍ, ṭ, ẓ = OK (common in Indonesian learning)
   → No underdots, no macrons beyond ā/ī/ū

2. Always hyphenate al- (ال)
   → al-kitāb, not alkitāb

3. Capitalization at start of sentence only
   → No capitalizing Arabic words mid-sentence

4. Apostrophe for both 'ayn and hamza
   → Context distinguishes them for beginners
   → Academic distinction (ʿ vs ʾ) confuses beginners

5. Transliteration matches pronunciation, not spelling
   → "ismī" not "ismī" (same in this case, but rule matters)
   → "kitābun" not "kitābun" when pronounced with tanwīn

6. Never use numeric substitutions (2, 3, 5, 7)
   → Common in informal Arabic chat, confusing for learners
```

### 24.3 When NOT to Use Transliteration

```
Stage 1: Transliteration ALWAYS shown
  - User hasn't learned the script yet
  - Essential bridge to Arabic reading

Stage 2: Transliteration shown, but smaller
  - Encourages reading Arabic script
  - Transliteration as backup only

Stage 3+: Transliteration hidden by default
  - Available on tap (tap transliteration icon to show)
  - User should be reading Arabic script directly
  - Exception: Long/complex words temporarily show transliteration

Stage 5+: Transliteration removed
  - User should read Arabic script fluently
  - Only shown for rare/unfamiliar words
```

## 25. Indonesian Translation Rules

### 25.1 Translation Standards

```
1. Translation is MEANING-FIRST, not word-for-word
   → "كَيْفَ حَالُكَ" = "Apa kabarmu" NOT "Bagaimana keadaanmu"
   → Natural Indonesian, not Arabic calque

2. Register matches usage context
   → Formal situations: formal Indonesian
   → Daily situations: casual Indonesian
   → Religious context: familiar Islamic Indonesian terminology

3. Avoid regional Indonesian variants
   → Use standard Bahasa Indonesia
   → Avoid Betawi, Javanese, or other regional terms

4. One meaning per word in early stages
   → Don't list multiple meanings for beginners
   → Multiple meanings introduced at Stage 4+

5. Example sentences are natural Indonesian
   → Not translated from Arabic syntax
   → written as a native Indonesian speaker would say it
```

### 25.2 Islamic Terminology Handling

```
Terms with religious significance get special treatment:

  Allāh (الله): Translated as "Allah" (capitalized, Indonesian standard)
    NOT "God" — "Allah" is the correct Indonesian term
  
  ṣalāh (صلاة): Translated as "salat" (Indonesian loanword)
    NOT "prayer" — "salat" is the standard Indonesian term
  
  Qur'ān (قرآن): Written as "Al-Qur'an"
    Standard Indonesian orthography with apostrophe

General rule: If a standard Indonesian Islamic term exists, use it.
Only translate to secular Indonesian when no standard term exists.
```

## 29. Adaptive Difficulty Strategy

### 29.1 Real-Time Adaptation

```
Within a single session, difficulty adapts to user performance:

  → Slightly tighter distractors on next battle question

  → Offer easier distractor set

  Difficulty +1 (more new words, harder distractors)

If average accuracy < 70%:
  Difficulty -1 (more review words, easier distractors)

If average accuracy 70-90%:
  Difficulty unchanged (optimal learning zone)

This maintains the "desirable difficulty" sweet spot
where learning is challenging but not frustrating.

## 30. Mistake Recovery System

### 30.1 Immediate Recovery (within session)

```
When user swipes wrong:
  1. Card shows correct meaning (500ms display)
  2. Word goes to "end of session review" pile
  3. Word reappears 2-3 cards later (immediate reinforcement)
  4. If wrong again: word appears AGAIN after 1 card
  5. If wrong 3 times: word is marked for "intensive review"
     but removed from current session (prevent frustration)

The user never sees the same wrong word more than 3 times per session.
After 3 failures, the word is deferred to the next session.
```

### 30.2 Next-Session Recovery

```
When user returns next session:

  Session starts with 2-3 words from "intensive review" pile
  These are REVIEW words (no new vocabulary yet)
  User gets 1 XP per correct intensive review word (lower pressure)
  After 3 consecutive correct: word leaves intensive review
  After failing again: word stays in intensive review, 
    but with SIMPLER presentation (larger text, clearer distractors)
```

### 30.3 Mistake Recovery Psychology

```
Design rules for mistake handling:

  1. Wrong answer NEVER plays a negative sound
     → Soft descending tone, not a buzzer
     → Same volume as correct answer, not louder

  2. Wrong answer NEVER shows a red "X" animation
     → Gentle red glow, not an error state
     → Focus on the correct answer reveal, not the mistake

  3. Combo breaks show no animation at all
     → Combo counter silently resets
     → No "COMBO BROKEN" text — just the number changing

  4. After wrong answer, the NEXT card is always easy
     → User gets a "free" correct answer to rebuild confidence
     → Easy card: review word user has mastered

  5. Never shame the user
     → No "Kamu salah!" text
     → No mascot disappointment for mistakes
     → Mascot only reacts to CORRECT answers (positive reinforcement)
```

## 31. Weakness Detection System

### 31.1 Weak Word Detection Criteria

```
A word enters the "weak" pool when ANY of these conditions are met:

  1. Accuracy < 60% over last 5 attempts
  2. Consecutive wrong ≥ 2
  3. EF (ease factor) < 2.0
  4. Not reviewed within expected window (nextReviewAt is in the past)
  5. Word was wrong in battle mode under time pressure

The weak pool is persisted across sessions.
Words exit the weak pool after 3 consecutive correct answers.
```

### 31.2 Weak Category Detection

```
A CATEGORY is flagged as weak when:

  Words in category average accuracy < 70%
  AND at least 5 words from the category have been attempted

When a category is weak:
  Review sessions pull MORE from this category
  New words from this category are PAUSED
  Battle questions favor this category's words
  
  Category exits weak status when:
    Average accuracy > 80%
    AND no word in category is individually flagged as weak
```

### 31.3 Weak Skill Detection

```
The four skills (vocabulary, listening, grammar, pronunciation)
are tracked independently:

  Vocabulary: Swipe accuracy
  Listening:  Audio exercise accuracy
  Grammar:    Grammar-specific question accuracy
  Pronunciation: (Future) AI speech recognition score

If a skill falls below 65%:
  → More sessions of that skill type
  → Easier content in that skill
  → Targeted tips at session start
```

## 32. Personalized Review System

### 32.1 Review Session Composition

```
A personalized review session is generated when user taps "Review":

Algorithm:
  1. Collect all words where nextReviewAt <= now
  2. Sort by: priority score (ascending EF → highest priority first)
  3. Select top 8 words from priority-sorted list
  4. If fewer than 8 words are due: fill with "close to due" words
  5. If more than 20 words are due: 
     warn user: "Kamu punya 25 kata untuk direview!"
     recommend: "Review 8 kata sekarang, sisanya besok?"

The review session has NO new words.
All cards are review cards with slightly larger XP rewards for completion.
```

### 32.2 Forced Review (Backlog Prevention)

```
If the review backlog exceeds 30 words:

  Forced review mode activates:
  - New vocabulary introduction is PAUSED
  - All sessions become review sessions
  - User is notified: "Ada 30+ kata yang menunggu review"
  - Backlog is cleared at ~8 words per session
  - Normal lessons resume when backlog < 10 words

This system ensures the "leaky bucket" never happens.
Every word learned gets the review time it needs.
```

## 35. Religious & Cultural Sensitivity Rules

### 35.1 Non-Negotiable Rules

```
1. Quranic vocabulary is treated with respect
   - Verses are NEVER used as "swipe cards"
   - Quranic words are identified with a special badge
   - Context: "This word appears in the Quran"
   - No gamification of sacred content

2. Islamic greetings are taught with cultural context
   - "السَّلَامُ عَلَيْكُمْ" includes explanation of its significance
   - Proper response "وَعَلَيْكُمُ السَّلَام" is taught simultaneously
   - Cultural note: when to use formal vs casual greetings

3. No stereotypes or caricatures
   - No stereotypes about Arab culture
   - No caricatures of religious practice
   - Characters are stylized geometric shapes (mascot = abstract circle)
   - Example scenarios are respectful of all Islamic traditions

4. Content is inclusive of all learners
   - Muslim learners: respects Islamic context
   - Non-Muslim learners: welcomes without presumption
   - Language focus: Arabic as a LANGUAGE, not only a religious language
   - Secular vocabulary taught alongside religious vocabulary

5. Dialect awareness
   - Content uses MSA (Modern Standard Arabic) as standard
   - Regional dialect notes: "In Egypt, people say..."
   - Never presents dialect as "wrong" — just different
```

### 35.2 Content That Requires Review

```
The following content types require EXTRA review by a human editor:

  - Any content involving Allah, prayer, or worship
  - Any content about cultural practices (weddings, funerals, etc.)
  - Any content that contrasts Islam with other religions
  - Any content about political topics
  - Any content about gender roles
  - Any content about historical events in the Arab world
  
  These topics should comprise <5% of total content.
  They are not avoided — they are handled with extra care.
```

## 36. Beginner Protection System

### 36.1 First Session Guarantees

```
The first session is DESIGNED for success:

  - 8 easy words only (cognates, short, clear meanings)
  - Distractor options are wildly different (no confusion risk)
  - Audio plays automatically on first card
  - Mascot appears with encouraging message
  - No timer, no pressure
  - First 3 cards are guaranteed to be words user likely knows
    (loanwords: madrasah, kitāb, qalam)
  - User cannot fail the first session
  - Minimum XP guaranteed: 50 (even if all wrong)
  - "Kamu hebat!" celebration regardless of score
```

### 36.2 Early Stage Protections (Levels 1-10)

```
1. No time pressure in any mode
   - Timer only appears in battle, battle unlocks at level 5
   
2. Always show transliteration
   - User isn't expected to read Arabic script yet
   
3. Audio auto-plays for new words
   - Reduces cognitive load of decoding script
   
4. Max 8 new words per session
   - Working memory limit for beginners
   
5. Same words appear across 3 sessions
   - Three exposures before any testing
   
6. Battle (when unlocked) only uses current lesson words
   - No mixing with old vocabulary
   
7. Wrong answers don't count against accuracy
   - First 10 sessions: accuracy tracking is hidden
   - After 10 sessions: accuracy tracking begins
   
8. Streak freeze activated automatically for first 7 days
   - User builds habit without pressure
```

### 36.3 Frustration Prevention

```
If user answers wrong 3 times in a row:
  → Session pauses
  → Mascot: encouraging message
  → Option: "Coba pelajaran yang lebih mudah?"
  → If accepted: switch to review session
  → If declined: continue, but next 2 cards are VERY easy

If user hasn't returned for 7+ days:
  → First session back: 100% review (no new words)
  → Lower difficulty enemies in battle
  → XP bonus: "Selamat datang kembali!" +50 XP
```

## 47. Ethical Learning Design

### 47.1 Non-Negotiable Ethical Rules

```
1. Learning Outcomes > Engagement Metrics
   - If a feature improves engagement but reduces learning, REMOVE IT
   - Retention is measured by WORDS REMEMBERED, not sessions completed

2. No Fake Progress
   - XP always corresponds to actual learning activity
   - No "participation trophies" — rewards are earned through demonstrated knowledge
   - No inflated numbers that hide lack of learning

3. No Punishment for Absence
   - Returning after a break is ALWAYS positive
   - No content locked away permanently
   - No decaying progress (words don't un-learn entirely)
   - Streak resets but knowledge stays

4. Transparent Difficulty
   - Users always know what they're learning
   - No hidden "trick" questions
   - Distractors are fair (same category, same difficulty level)

5. No Addiction Loops
   - Session timer: "Kamu sudah belajar X menit"
   - Daily limit: suggestions to stop after 3 sessions
   - No audio/visual rewards for extended sessions
   - Streak is a gentle nudge, not an anxiety source

6. Cognitive Diversity
   - Content works for different learning styles
   - Multiple modalities (visual, audio, kinesthetic via swipe)
   - Adjustable pace (slow/normal speed options)
   - No assumptions about user's background knowledge
```

### 47.2 Anti-Manipulation Design

```
Harf explicitly avoids these manipulative patterns:

  ✗ "You're about to lose your streak!" (urgency manipulation)
  ✓ "You have a streak freeze available if needed." (informational)

  ✗ "Only 3 people in your league — compete now!" (scarcity pressure)
  ✓ "Your league has 50 members. Top 10 promote this week."

  ✗ "You almost got it!" on wrong answer (near-miss manipulation)
  ✓ "This word is tricky! Let's try again later."

  ✗ Random XP bonuses that require watching ads
  ✓ Random XP as a genuine surprise for completing lessons

  ✗ Push notifications: "We miss you!" (guilt)
  ✓ Push notifications: "1 word waiting for you" (curiosity)

  ✗ Countdown timers on content access
  ✓ Open access to all learned content, always available
```

## 48. Anti-Burnout Rules

### 48.1 Session Limits

```
Hard limit: 90 minutes of active learning per day
  After 90 minutes: session button changes to "Istirahat yuk!"
  User CAN still play, but the system explicitly suggests a break
  
Soft limit: 3 complete lessons per day
  After 3 lessons: "Kamu sudah belajar 3 sesi hari ini"
  Optional review or battle still available
  New lesson content is locked (prevents over-consumption)
  
Daily mission limit: 3 missions per day
  Missions refresh daily, but don't stack indefinitely
  Unclaimed missions expire (encourages daily engagement, not bingeing)
```

### 48.2 Content Repetition Diversity

```
To prevent boredom with repeated review words:

  After 5 correct reviews of the same word:
    → Switch to different question type (e.g., reverse translation)
    → Use different example sentence
    → Pair with a different word for comparison
    → Increase distractor difficulty

  After 10 correct reviews of the same word:
    → Word is promoted to "mastered" status
    → Review frequency drops to monthly
    → Word is replaced in normal rotation
```

### 48.3 Comeback Flow (After Break)

```
When user returns after 3+ days away:

  Session 1: "Selamat datang kembali!"
    100% review content (0% new words)
    Lower difficulty enemies in battle
    +50 XP comeback bonus
    
  Session 2: 75% review, 25% new
    Normal difficulty
    No comeback bonus
    
  Session 3: Normal ratio (66% new, 33% review)
    Full difficulty
    Back to regular progression
    
  The comeback arc takes 3 sessions to normalize.
  No guilt, no punishment, no "you missed X days" message.
```
